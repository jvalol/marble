# Specs

What the game does, one file per area. `TEMPLATE.md` is the starting point for a
new one, and `CLAUDE.md` in the repo root describes the flow.

Specs are numbered in the order they were written. The number is an identifier,
not a priority, and it never changes once a spec exists.

| Spec | Covers |
| --- | --- |
| [0001](0001-rolling.md) | How the marble moves, and falls |
| [0002](0002-course.md) | Platforms, gems, checkpoints, the goal |
| [0003](0003-the-run.md) | The clock, falling, finishing, pausing |
| [0004](0004-camera-and-controls.md) | The following camera, mouse and keys |
| [0005](0005-landing-sound.md) | The thud when the marble lands |
